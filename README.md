# soccer-json-details

이 저장소는 축구 경기 상세 정보를 JSON 형식으로 저장하고 제공하는 GitHub Pages 기반 저장소입니다.

## 폴더 구조
📂 soccer-json-details
├── 📂 data # ✅ 경기 상세 JSON 저장
├── 📂 .github/workflows # ✅ GitHub Actions 설정
├── requirements.txt # ✅ Python 종속성 목록
├── README.md # ✅ 프로젝트 설명 문서

## GitHub Actions 자동화
이 저장소는 `.github/workflows/`를 통해 일정 주기로 JSON 데이터를 자동 업데이트합니다.
